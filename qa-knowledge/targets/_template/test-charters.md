## 実行の進め方

`Review-Status` を `Approved` にしてから、チャーター駆動モードで実行する。

```
/explore url=<対象URL> charter=qa-knowledge/targets/<slug>/test-charters.md
```

`/explore` はこのファイルの**実行順・深さ・ケース数・狙う欠陥仮定に従い**、
チャーターに無い観点には手を出さない(観点リストの優先度 P0→P3 は使わない)。
`Approved` でなければ探索を始めずに停止する。

各イテレーションで「状態」欄が更新される:

| 状態 | 意味 |
|---|---|
| `未実行` | まだ着手していない |
| `実行中` | 着手済み |
| `完了` | **完了条件を満たした**。テストが落ちても、バグを起票できたなら完了 |
| `未確認のまま終了` | 完了条件を満たせなかった。理由を備考に残す |

セッション終了時、`未確認のまま終了` と `未実行` は**残存リスクとして報告される**
(紐づくリスクIDつき)。テストの成否ではなく、完了条件で判断する。
